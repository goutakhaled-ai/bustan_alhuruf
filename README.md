# بستان الحروف 🌳
تطبيق لتعليم اللغة العربيّة للأطفال (للاستعمال الشخصي).

## التحويل إلى APK عبر GitHub
1. أنشئ مستودعًا جديدًا (Repository) على GitHub.
2. ارفع كلّ محتوى هذا المجلّد كما هو (مع مجلّد `.github`).
3. افتح تبويب **Actions** ← سيبدأ البناء تلقائيًا (أو اضغط Run workflow).
4. بعد انتهاء البناء (حوالي 5 دقائق) حمّل الملفّ `bustan-alhuruf-apk` من أسفل الصفحة، وفكّ الضغط، ثمّ ثبّت `app-debug.apk` على الهاتف.

## الصوت
يعتمد التطبيق على محرّك تحويل النصّ إلى كلام في الهاتف.
إن لم يُسمع الصوت: الإعدادات ← تحويل النصّ إلى كلام ← محرّك Google ← تثبيت بيانات الصوت ← العربيّة.
